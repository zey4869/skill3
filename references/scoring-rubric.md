# 本地小店增长诊断评分规则

总分 90 分，共 9 个维度，每项 0–10 分。

---

## 1. 路过识别度

判断：顾客路过门店时，3 秒内能不能知道你卖什么、为什么值得进来。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 看不出品类，看不出主推，门头弱或混乱 |
| 4–6 | 能看出品类，但卖点不清，缺少进店理由 |
| 7–8 | 品类清楚，有主推信息，但还不够强 |
| 9–10 | 品类、招牌、价格/场景理由都清楚，路过容易被吸引 |

常见动作：

- 门口增加主推产品立牌；
- 强化品类名；
- 加价格锚点；
- 加“第一次来推荐点什么”。

---

## 2. 产品钩子

判断：有没有一个顾客听完就明白、看见就想试的招牌理由。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 产品很多但没有重点 |
| 4–6 | 有主推，但理由普通 |
| 7–8 | 有明确爆品或招牌，但传播表达还能优化 |
| 9–10 | 产品钩子强，容易拍、容易讲、容易被顾客记住 |

常见动作：

- 选 1–3 个主推产品；
- 给每个主推产品写一句成交理由；
- 把产品角色分为引流款、主推款、利润款、加购款。

---

## 3. 价格结构

判断：价格是否能同时承担引流、成交、利润和加购。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 价格混乱，低价产品抢走利润 |
| 4–6 | 有基础价格，但缺少层级和加购 |
| 7–8 | 有引流款和主推款，但利润款不明显 |
| 9–10 | 引流、主推、利润、加购结构清楚 |

常见动作：

- 设置低门槛引流款；
- 强化主推利润款；
- 增加加料/升级/组合；
- 限制低价款适用范围。

---

## 4. 团购转化

判断：团购是否能让用户点击、理解、下单、到店，并且不破坏利润。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 主图差、标题弱、价格结构伤利润 |
| 4–6 | 有团购但缺少清晰卖点 |
| 7–8 | 团购可转化，但主推与加购不足 |
| 9–10 | 团购结构清楚，能引流也能提升客单价 |

常见动作：

- 改主图；
- 改标题；
- 改详情说明；
- 做三层团购：引流款、主推款、多人/加购款。

---

## 5. 菜单效率

判断：顾客看菜单时是否能快速知道该点什么。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 菜单拥挤、混乱、无推荐 |
| 4–6 | 信息完整但缺少引导 |
| 7–8 | 有推荐，但层级还能优化 |
| 9–10 | 顾客能迅速完成点单，且被引导到主推/利润产品 |

常见动作：

- 增加推荐位；
- 精简选择；
- 分区：招牌、人气、高性价比、加购；
- 把高毛利产品放到更显眼位置。

---

## 6. 内容资产

判断：线上内容是否能证明这家店值得来。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 几乎没有内容或内容像硬广 |
| 4–6 | 有内容但不稳定、不聚焦、不转化 |
| 7–8 | 有一定内容资产，但缺少系列和本地关键词 |
| 9–10 | 内容能持续提供到店理由，并和团购/产品协同 |

常见动作：

- 建立固定系列；
- 每周至少 3 条低成本内容；
- 强化本地关键词；
- 每条视频对应一个转化目标。

---

## 7. 视觉记忆点

判断：门店、产品、包装、环境是否有能被顾客拍照和记住的画面。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 没有记忆点，画面杂乱或普通 |
| 4–6 | 有基础视觉，但不利于传播 |
| 7–8 | 有可拍点，但没有系统利用 |
| 9–10 | 产品、空间、物料都容易出片，形成传播资产 |

常见动作：

- 增加一个顾客拍照点；
- 统一菜单/台卡/海报风格；
- 改团购主图；
- 强化产品摆盘和出餐画面。

---

## 8. 复购机制

判断：顾客来过一次之后，有没有再次来的理由。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 完全没有复购机制 |
| 4–6 | 有会员/优惠，但引导弱 |
| 7–8 | 有复购动作，但没有内容和评价联动 |
| 9–10 | 有明确老客维护、评价引导、复购产品和周期活动 |

常见动作：

- 老客福利；
- 第二次到店券；
- 评价引导；
- 周期性新品/隐藏菜单；
- 顾客群或朋友圈维护。

---

## 9. 执行难度

判断：建议是否能被老板和员工真正执行。

| 分数 | 判断标准 |
|---:|---|
| 0–3 | 动作复杂、成本高、老板做不了 |
| 4–6 | 能做，但需要较多配合 |
| 7–8 | 大部分动作低成本可执行 |
| 9–10 | 动作简单清楚，老板/员工当天就能开始 |

常见动作：

- 把动作拆小；
- 明确谁做；
- 降低成本；
- 先试 7 天；
- 用简单指标判断效果。

---

## 总分解释

```text
80–90 分：基础较好，适合做内容放大和品牌升级。
65–79 分：有明显机会，优先优化团购、门头、菜单和内容钩子。
50–64 分：问题较多，需要先修产品/价格/菜单/门头，再做内容。
50 分以下：不建议先卖高价服务，先做低价诊断或单点整改。
```

---

## 评分注意事项

- 不要为了成交故意压低分；
- 不要为了讨好老板故意打高分；
- 没有证据的维度标记为“待补充”；
- 分数只是沟通工具，核心是优先级；
- 每个低分项必须给出一个低成本动作。
