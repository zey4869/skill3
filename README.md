# local-shop-growth-diagnosis

本地小店获客与增长诊断 Codex Skill。

它用于把一家线下小店从“看一眼觉得哪里不对”，转化成一套可采集、可诊断、可汇报、可成交、可执行、可复盘的增长服务流程。

核心路径：

```text
找店 → 观察 → 询问信息 → 免费/低价诊断 → 产品级详细报告 → 主业务成交 → 后续高价值附加业务
```

## 3. 核心能力

### 3.1 门店采集

通过店名、品类、位置、门头、菜单、团购截图、平台账号、老板描述等信息，建立门店基础档案。

### 3.2 九维诊断

从 9 个维度判断一家小店当前的问题和机会：

1. 路过识别度
2. 产品钩子
3. 价格结构
4. 团购转化
5. 菜单效率
6. 内容资产
7. 视觉记忆点
8. 复购机制
9. 执行难度

### 3.3 报告生成

支持生成：

- 免费版轻诊断
- 低价版基础报告
- 付费版详细报告
- 7 天行动表
- 14 天行动表
- 30 天增长计划
- 老板能看懂的销售话术

### 3.4 服务转化

支持从免费诊断升级到：

- 49 / 99 / 199 元基础报告
- 399 / 699 / 999 元详细方案
- 月度内容顾问
- 团购主图设计
- 菜单优化
- 门店视觉物料
- 短视频脚本包
- 本地生活账号陪跑

## 6. 推荐工作流

### 第一步：找店

观察门头、品类、位置、人流、团购、内容账号。

### 第二步：轻采集

至少拿到：

- 店名
- 品类
- 门头照片
- 菜单照片
- 团购截图
- 老板当前问题

### 第三步：免费诊断

输出 1–2 页，指出 3 个机会点、3 个问题、3 个低成本动作。

### 第四步：低价报告

如果老板认可，升级到 49 / 99 / 199 元基础报告。

### 第五步：详细方案

进一步生成 399 / 699 / 999 元产品级报告，包括竞品、团购、短视频、视觉、行动表。

### 第六步：后续服务

从报告延伸到主图设计、菜单优化、短视频脚本、门店视觉、账号陪跑。

## 7. 核心原则

小店老板关心的不是概念，而是：

```text
能不能多来人；
能不能多卖钱；
能不能少浪费；
能不能少折腾但有效果。
```

所以输出必须做到：

- 直接
- 具体
- 低成本
- 老板听得懂
- 员工能执行
- 不装大词
- 不编数据
- 每个建议都有动作
